# CSS Display Demo

Web Link: https://karanjthakur.github.io/CSS-Display/

This folder contains a simple HTML and JavaScript demo that explains how CSS `display` values affect layout.

## What it shows

- `block` elements, which take up the full available width and respect width and height settings
- `inline` elements, which stay in the text flow and ignore width and height
- `inline-block` elements, which stay inline but still respect width and height
- Interactive sliders for changing the width and height of each example in real time

## Files

- `index.html` - the main page with the example markup and styles
- `script.js` - slider logic that updates the displayed boxes live

## How to use

1. Open `index.html` in a browser.
2. Move the sliders to change the size of each display example.
3. Compare how each `display` value responds differently.

## Learning goal

This demo is useful for understanding one of the most important CSS layout differences:

- `block` behaves like a box
- `inline` behaves like text
- `inline-block` combines inline flow with box sizing

## Notes

The example is self-contained and does not require any build step or external dependencies.
